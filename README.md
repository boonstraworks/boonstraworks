# Hoi, ik ben Steven

Ik bouw websites, tools en koppelingen voor ondernemers in de **Kop van Noord-Holland**, onder de naam [BoonstraWorks](https://boonstraworks.nl). Twaalf jaar ervaring, kennis van nu, en het liefst software die gewoon blijft werken.

### Eigen werk dat elke dag draait

| | Project | Wat het is |
|---|---|---|
| 🚨 | [112hier.nl](https://112hier.nl) | Hulpdienstmeldingen live op de kaart, rechtstreeks uit de lucht geplukt met een eigen antenne |
| 🏠 | [homeassistant-112hier](https://github.com/boonstraworks/homeassistant-112hier) | De gratis Home Assistant-integratie van 112hier: meldingen, NL-Alert en aardbevingen in je smart home |
| 🔋 | [TopAccu.nl](https://topaccu.nl) | Mijn eigen webshop voor accu's en opladers, met een accuzoeker op typenummer |

| 🧮 | [Rekencheck.nl](https://rekencheck.nl) | Achtendertig rekenhulpen die laten zien hoe ze aan het antwoord komen |
